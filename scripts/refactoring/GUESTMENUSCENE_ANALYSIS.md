# Анализ GuestMenuScene

> Карта методов, зависимостей и логических групп для рефакторинга

**Дата анализа**: Сегодня  
**Размер файла**: 1364 строки

**Количество зависимостей**: 5 извлеченных классов

## 📊 Структура класса

### Зависимости (уже извлечены)

- `menu_state: GuestMenuState` - состояние меню (выбранный/наведенный гость)
- `keyboard_navigator: GuestMenuKeyboardNavigator` - клавиатурная навигация
- `ui_renderer: GuestMenuUIRenderer` - рендеринг UI элементов
- `text_updater: GuestMenuTextUpdater` - обновление текстов
- `balance_renderer: GuestMenuBalanceRenderer` - рендеринг балансов

### UI Узлы

- `background_layer: Control` - фон (стол)
- `table_texture: TextureRect` - текстура стола
- `ghosts_layer: Control` - слой призраков
- `guests_layer: Control` - слой гостей
- `hover_glows_layer: Control` - слой свечений hover
- `dossiers_layer: Control` - слой досье
- `clickable_zones_layer: Control` - кликабельные зоны
- `ui_layer: Control` - UI элементы
- `ok_button: Button` - кнопка OK
- `character_option: OptionButton` - выбор характера
- `wealth_option: OptionButton` - выбор обеспеченности

### Массивы узлов для 6 гостей

- `ghost_textures: Array[TextureRect]` - призраки
- `guest_textures: Array[TextureRect]` - материальные гости
- `hover_glow_textures: Array[TextureRect]` - свечения hover
- `dossier_textures: Array[TextureRect]` - досье
- `balance_labels: Array[Label]` - labels баланса
- `change_labels: Array[Label]` - labels изменения баланса
- `balance_plus_buttons: Array[Button]` - кнопки +
- `balance_minus_buttons: Array[Button]` - кнопки -
- `guest_slots: Array[Control]` - кликабельные зоны

### Состояние

- `last_selected_level: NavigationLevel` - последний выделенный уровень
- `last_selected_guest_id: int` - последний выделенный гость

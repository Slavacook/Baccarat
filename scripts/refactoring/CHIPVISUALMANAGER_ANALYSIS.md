# Анализ ChipVisualManager

> Карта методов, зависимостей и логических групп для рефакторинга

**Дата анализа**: Сегодня  
**Размер файла**: 1135 строк  
**Количество методов**: 29  
**Количество зависимостей**: 1 (scene_root: Node2D)

## 📊 Структура класса

### Зависимости

- `scene_root: Node2D` - корневой узел сцены для добавления фишек
- `chip_nodes: Dictionary` - словарь узлов фишек из сцены
- `active_chips: Array[ChipInstance]` - массив активных фишек
- `extra_chips: Dictionary` - дополнительные фишки (копии)

### Состояние

- `current_textures: Dictionary` - текущие текстуры фишек
- `default_positions: Dictionary` - основные позиции фишек
- `current_mode: PositionMode` - режим позиций (всегда GUEST)
- `_saved_visibility: Dictionary` - сохранённое состояние видимости (для Heart Bet)

### Константы

- `CHIP_TEXTURES: Dictionary` - текстуры фишек по типам
- `ALTERNATIVE_POSITIONS: Dictionary` - альтернативные позиции фишек
- `PROBABILITY_WEIGHTS: Array` - веса вероятностей для REALISTIC режима
- `RANGES_6: Array` - диапазоны количества для типов с 6 позициями

### Классы

- `ChipInstance` - данные об индивидуальной фишке

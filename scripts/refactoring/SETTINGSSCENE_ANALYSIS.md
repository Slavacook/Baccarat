## ⚠️ Риски и ограничения

### Сложности:
1. **Много UI узлов** - все узлы определены в SettingsScene
2. **Зависимости от менеджеров** - много внешних зависимостей
3. **Сложная навигация** - логика навигации тесно связана с UI

### Меры предосторожности:
- Маленькие шаги
- Тестирование после каждого шага
- Сохранение обратной совместимости
- Передача UI узлов через параметры или свойства

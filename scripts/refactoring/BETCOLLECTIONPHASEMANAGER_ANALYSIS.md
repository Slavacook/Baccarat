- `payout_queue_manager: PayoutQueueManager` - менеджер очереди выплат

- `actual_winner: String` - победитель раунда

### Состояние

- `current_mode: CollectionMode` - текущий режим (NONE, COLLECT, PAY)
- `collected_losing_bets: Array[String]` - список собранных ставок (для обратной совместимости)
- `collected_bets_by_id: Dictionary` - словарь собранных ставок с position_index
- `collection_sequence: Dictionary` - последовательности для сбора
- `payment_sequence: Dictionary` - последовательности для оплаты
- `collection_progress: Dictionary` - прогресс сбора по группам
- `payment_progress: Dictionary` - прогресс оплаты по группам
- `_line_position_cache: Dictionary` - кэш номеров позиций
- `is_processing: bool` - флаг блокировки для защиты от параллельных операций

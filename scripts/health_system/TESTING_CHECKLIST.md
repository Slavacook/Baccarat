# Чеклист для ручного тестирования Health System

## Подготовка

1. Убедитесь, что проект компилируется без ошибок
2. Запустите игру: `godot --path . scenes/Game.tscn`

## Базовое тестирование режима выживания

### 1. Активация/деактивация режима выживания

- [ ] Откройте настройки (Settings)
- [ ] Включите "Режим выживания" (Survival Mode)
- [ ] **Ожидаемый результат**: Появляются 7 полных сердечек в верхней части экрана
- [ ] Выключите режим выживания
- [ ] **Ожидаемый результат**: Сердечки исчезают, появляется статистика (StatsLabel)

### 2. Потеря жизни при ошибке

- [ ] Включите режим выживания
- [ ] Начните игру (раздайте карты)
- [ ] Сделайте неправильный выбор (например, закажите третью карту когда не нужно)
- [ ] **Ожидаемый результат**:
  - Одно сердце становится пустым (крайнее справа)
  - Сердечки мигают красным (анимация потери жизни)
  - В консоли: "Жизнь потеряна! Осталось: 6"

### 3. Несколько ошибок подряд

- [ ] Сделайте 3 ошибки подряд
- [ ] **Ожидаемый результат**:
  - Остаётся 4 полных сердца
  - Каждая ошибка уменьшает жизни на 1
  - Анимация потери жизни срабатывает каждый раз

### 4. Game Over

- [ ] Сделайте 7 ошибок (или используйте подсказку 7 раз)
- [ ] **Ожидаемый результат**:
  - Все сердца пустые
  - Появляется экран Game Over
  - В консоли: "GAME OVER! Режим выживания завершён"

## Тестирование Heart Bet (Ставка сердцем)

### 5. Залог сердца

- [ ] Включите режим выживания
- [ ] Дождитесь срабатывания триггера Heart Bet (например, Banker Six)
- [ ] Нажмите на карту "Шанс"
- [ ] Выберите сердце (Player/Banker/Tie)
- [ ] **Ожидаемый результат**:
  - Последнее полное сердце (крайнее справа) меняет вид (оранжевый оттенок или специальная текстура)
  - В консоли: "❤️ Сердце #X в залоге"

### 6. Возврат залога (Tie draw)

- [ ] Заложите сердце
- [ ] Начните раздачу
- [ ] Если выпало Tie (при ставке на Player/Banker)
- [ ] **Ожидаемый результат**:
  - Заложенное сердце возвращается (становится обычным)
  - В консоли: "❤️ Сердце #X возвращено из залога"

### 7. Выигрыш Heart Bet

- [ ] Заложите сердце
- [ ] Начните раздачу
- [ ] Угадайте победителя правильно
- [ ] **Ожидаемый результат**:
  - Залог возвращается
  - Добавляется жизнь (для Player/Banker: +1, для Tie: +6)
  - Сердечки мигают зелёным (анимация получения жизни)
  - В консоли: "❤️ +X жизней!"

### 8. Проигрыш Heart Bet

- [ ] Заложите сердце
- [ ] Начните раздачу
- [ ] Не угадайте победителя
- [ ] **Ожидаемый результат**:
  - Заложенное сердце сгорает (становится пустым)
  - Жизни уменьшаются на 1
  - В консоли: "❤️💔 Сердце #X потеряно!"

## Тестирование PayoutOverlay

### 9. Отображение жизней в PayoutOverlay

- [ ] Включите режим выживания
- [ ] Пройдите раунд до выплаты
- [ ] Откройте PayoutOverlay
- [ ] **Ожидаемый результат**:
  - В заголовке показывается одно сердце + число (например, "♥ 5")
  - Количество жизней соответствует текущему состоянию

### 10. Обновление жизней в PayoutOverlay

- [ ] Откройте PayoutOverlay (показывает, например, 5 жизней)
- [ ] Сделайте ошибку в выплате (неправильно соберите фишки)
- [ ] **Ожидаемый результат**:
  - Количество жизней в PayoutOverlay обновляется (становится 4)
  - Сердце в SurvivalModeUI тоже обновляется

## Тестирование синхронизации

### 11. Синхронизация между сценами

- [ ] Включите режим выживания (5 жизней)
- [ ] Перейдите в PayoutScene
- [ ] Вернитесь обратно
- [ ] **Ожидаемый результат**:
  - Количество жизней сохраняется (5)
  - Сердечки отображаются правильно

### 12. Сброс при новой игре

- [ ] Включите режим выживания
- [ ] Потеряйте несколько жизней (например, осталось 3)
- [ ] Нажмите "Рестарт" или начните новую игру
- [ ] **Ожидаемый результат**:
  - Жизни сбрасываются на 7
  - Все сердца полные

## Тестирование граничных случаев

### 13. Максимум жизней

- [ ] Включите режим выживания (7 жизней)
- [ ] Выиграйте Heart Bet (добавьте жизни)
- [ ] **Ожидаемый результат**:
  - Жизни остаются 7 (не превышают максимум)
  - В консоли: "❤️ +X жизней! (запрошено: Y, добавлено: X, итого: 7)"

### 14. Ноль жизней

- [ ] Доведите жизни до 0
- [ ] Попробуйте сделать ещё одну ошибку
- [ ] **Ожидаемый результат**:
  - Game Over уже произошёл
  - Дополнительные ошибки не уменьшают жизни (остаётся 0)

## Проверка консоли

Во время тестирования проверьте консоль на наличие ошибок:

- [ ] Нет ошибок типа "null pointer"
- [ ] Нет ошибок типа "method not found"
- [ ] Все сообщения логирования корректны

## Быстрая проверка (минимальный набор)

Если нет времени на полное тестирование, проверьте минимум:

1. ✅ Включить режим выживания → появляются 7 сердечек
2. ✅ Сделать ошибку → одно сердце становится пустым
3. ✅ Заложить сердце (Heart Bet) → сердце меняет вид
4. ✅ Выиграть Heart Bet → добавляется жизнь
5. ✅ Довести до 0 жизней → Game Over

Если все эти пункты работают, основная функциональность в порядке.

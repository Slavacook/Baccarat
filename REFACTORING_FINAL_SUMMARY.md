## 🛠️ Технологии и подходы

### Использованные техники рефакторинга

1. **Extract Class** - извлечение классов из больших файлов
2. **Dependency Injection** - передача зависимостей через конструкторы
3. **Single Responsibility Principle** - один класс = одна ответственность
4. **Event-Driven Architecture** - коммуникация через EventBus
5. **Manager Pattern** - организация кода через менеджеры

### Инструменты

- **Godot 4.5** - игровой движок
- **GDScript 3.0** - язык программирования
- **GUT** - фреймворк для unit-тестирования
- **Git** - система контроля версий

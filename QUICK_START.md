# Quick Start - Быстрый старт для новых задач

> Пошаговое руководство для начала работы над новой функцией

## 🎯 Шаг 1: Понять задачу

1. **Что нужно сделать?** (краткое описание)
2. **Где это должно работать?** (какой модуль/система)
3. **Какие зависимости?** (какие классы нужны)

## 🔍 Шаг 2: Найти существующий код

### Поиск по ответственности
- **UI изменения** → `scripts/ui/`
- **Игровая логика** → `scripts/GamePhaseManager.gd`
- **Выплаты** → `scripts/payout/`
- **Ставки** → `scripts/bet_system/`
- **События** → `scripts/autoload/EventBus.gd`

### Использование индекса
1. Открой `CLASS_INDEX.md`
2. Найди нужную категорию
3. Посмотри зависимости класса

## 📝 Шаг 3: План реализации

### Для новой функции:

```markdown
1. [ ] Создать класс/метод
2. [ ] Добавить сигналы в EventBus (если нужно)
3. [ ] Подписаться на события (если нужно)
4. [ ] Реализовать логику
5. [ ] Добавить локализацию (если нужно)
6. [ ] Протестировать
```

### Для изменения существующей функции:

```markdown
1. [ ] Найти класс/метод
2. [ ] Понять зависимости
3. [ ] Внести изменения
4. [ ] Проверить, не сломал ли что-то
5. [ ] Протестировать
```

## ✅ Шаг 5: Чеклист перед коммитом

## 🚀 Типичные сценарии

### Сценарий 1: Добавить новое событие

```markdown
1. Открой `scripts/autoload/EventBus.gd`
2. Добавь сигнал: `signal my_new_event(param: String)`
3. Обнови `CLAUDE.md` (секция EventBus)
4. Используй: `EventBus.my_new_event.emit("value")`
5. Подпишись: `EventBus.my_new_event.connect(_on_event)`
```

### Сценарий 2: Добавить новый UI элемент

```markdown
1. Создай UI менеджер в `scripts/ui/MyUIManager.gd`
2. Добавь в `UIManager` (фасад)
3. Используй шаблон из CODE_EXAMPLES.md
4. Подключи сигналы через EventBus
```

### Сценарий 3: Изменить правила игры

```markdown
1. Открой `scripts/BaccaratRules.gd`
2. Измени нужный метод
3. Проверь, что не сломал логику
4. Протестируй разные сценарии
```

### Сценарий 4: Добавить новый тип ставки

```markdown
1. Создай класс в `scripts/bet_types/MyBetType.gd`
2. Наследуй от `IBetType`
3. Реализуй методы интерфейса
4. Добавь в `BetTypeFactory`
```

### Сценарий 5: Добавить новую карту шанса

```markdown
1. Создай класс в `scripts/chance_cards/implementations/MyCard.gd`
2. Наследуй от `BaseChanceCard`
3. Реализуй `apply_effect()`
4. Зарегистрируй в `ChanceCardManager`
```

## 📚 Полезные команды

### Поиск в коде
```bash
# Найти использование класса
grep -r "ClassName" scripts/

# Найти все сигналы EventBus
grep -r "EventBus\." scripts/

# Найти все подписки на событие
grep -r "\.connect(" scripts/
```

### Запуск проекта
```bash
# Открыть в редакторе
godot --editor --path .

# Запустить игру
godot --path . scenes/Game.tscn
```

## 💡 Советы

1. **Начинай с малого** - сначала сделай простую версию
2. **Используй существующие паттерны** - не изобретай велосипед
3. **Тестируй часто** - запускай игру после каждого изменения
4. **Следуй правилам** - используй EventBus, типизацию, комментарии
5. **Документируй изменения** - обновляй документацию при необходимости

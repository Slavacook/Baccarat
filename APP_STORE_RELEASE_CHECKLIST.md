# App Store Release Checklist

Финальный короткий чеклист перед сборкой, TestFlight и отправкой в ревью.

## 1. Код и проект

- [ ] В релизной ветке нет случайных debug-правок и незапланированных изменений
- [ ] Учебные функции оформлены как часть продукта
- [ ] В проекте нет жёстких локальных путей и опасных dev-хвостов
- [ ] Название продукта выровнено как `Баккара Тренажёр / Baccarat Trainer`
- [ ] Релизные тексты про обучение и отсутствие реальных ставок готовы

## 2. Экспортные настройки

- [ ] Заполнен корректный Apple Team ID
- [ ] Заполнены `short_version` и `version`
- [ ] Проверен и подтверждён bundle identifier для iOS
- [ ] Заполнен bundle identifier для macOS, если нужен macOS релиз
- [ ] Подставлены iOS/App Store иконки в `export_presets.cfg`
- [ ] Проверены codesign / notarization поля для нужных платформ
- [ ] Экспортные пути в `export_presets.cfg` соответствуют релизному билду

## 3. Store-материалы

- [ ] Готова App Store иконка 1024x1024
- [ ] Подготовлены скриншоты iPhone
- [ ] Подготовлены скриншоты iPad
- [ ] Подготовлен Privacy Policy URL
- [ ] Подготовлен Support URL
- [ ] Заполнен возрастной рейтинг
- [ ] Подготовлены privacy details для App Store Connect
- [ ] Проверены финальные store-тексты из `APP_STORE_TEXTS_DRAFT.md`

## 4. Перед сборкой

- [ ] Пройден быстрый smoke-check проекта
- [ ] Прогнаны доступные тесты
- [ ] Собран релизный экспорт без ошибок
- [ ] Сохранён финальный артефакт сборки

## 5. Перед TestFlight

- [ ] Загружен билд в App Store Connect
- [ ] В карточке приложения заполнены основные метаданные
- [ ] Добавлена заметка для ревью про учебный характер приложения
- [ ] Проверено, что `Ручная раздача` и `Свободная тренировка` описаны как учебные инструменты

## 6. Перед ревью

- [ ] Пройден ручной чеклист на iPhone/iPad
- [ ] Проверены старт игры, обучение, сохранения, звук и возврат из фона
- [ ] Проверены учебные режимы и их понятность для пользователя
- [ ] Проверено, что приложение не выглядит как real-money gambling app
- [ ] Уточнены финальные контакты поддержки и ссылки

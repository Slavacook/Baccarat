# Пошаговый гайд по рефакторингу

> Детальная инструкция для безопасного рефакторинга одного шага

## 🎯 Как использовать этот гайд

1. Выбери шаг из `SAFE_REFACTORING_PLAN.md`
2. Следуй инструкциям ниже
3. Проверяй каждый пункт чеклиста
4. Коммить только после успешной проверки

---

## 📋 ШАБЛОН ДЛЯ КАЖДОГО ШАГА

### ШАГ 1: Подготовка (5-10 минут)

#### 1.1 Создать ветку
```bash
# Перейти на main/master
git checkout main  # или master

# Обновить
git pull

# Создать ветку для рефакторинга
git checkout -b refactoring/step-X.X-description

# Например:
git checkout -b refactoring/step-1.1-improve-structure
```

#### 1.2 Зафиксировать текущее состояние
```bash
# Убедиться, что всё закоммичено
git status

# Если есть изменения, закоммитить
git add .
git commit -m "Before refactoring step X.X"
```

#### 1.3 Проанализировать зависимости
```bash
# Запустить анализ
./tools/analyze_dependencies.sh scripts/GameController.gd

# Изучить вывод
# Понять, какие классы используются
# Понять, какие методы большие
```

**Чеклист:**
- [ ] Ветка создана
- [ ] Текущее состояние закоммичено
- [ ] Зависимости проанализированы
- [ ] План действий понятен

---

### ШАГ 2: Рефакторинг (30-60 минут)

#### 2.1 Изучить код
- [ ] Прочитать код, который будешь менять
- [ ] Понять, что он делает
- [ ] Понять зависимости
- [ ] Найти все места использования

#### 2.2 Создать новый класс/метод (если нужно)
```gdscript
# Пример: создание нового класса
# res://scripts/utils/MyNewClass.gd
class_name MyNewClass
extends RefCounted

func _init():
    """Инициализация"""
    pass

func do_something() -> void:
    """Описание метода"""
    pass
```

**Чеклист:**
- [ ] Новый класс создан
- [ ] Методы перемещены/созданы
- [ ] Типизация добавлена
- [ ] Комментарии добавлены

#### 2.3 Обновить существующий код
- [ ] Заменить старый код на использование нового класса
- [ ] Обновить все места использования
- [ ] Убрать дублирование

**Чеклист:**
- [ ] Старый код заменён
- [ ] Все использования обновлены
- [ ] Дублирование устранено

---

### ШАГ 3: Проверка компиляции (5 минут)

#### 3.1 Проверить в Godot
```bash
# Открыть проект в Godot
godot --editor --path .

# Проверить, что нет ошибок компиляции
# Смотреть в панель "Output" → "Errors"
```

**Чеклист:**
- [ ] Нет ошибок компиляции
- [ ] Нет критических предупреждений
- [ ] Код компилируется успешно

---

### ШАГ 4: Автоматическая проверка (5 минут)

#### 4.1 Запустить скрипт проверки
```bash
# Запустить проверку рефакторинга
./tools/check_refactoring.sh

# Проверить вывод
# Исправить предупреждения (если есть)
```

**Чеклист:**
- [ ] Скрипт проверки прошёл
- [ ] Нет критических ошибок
- [ ] Предупреждения исправлены (или понятны)

---

### ШАГ 5: Ручное тестирование (10-15 минут)

#### 5.1 Запустить игру
```bash
# Запустить игру
godot --path . scenes/Game.tscn

# Или через редактор: F5
```

#### 5.2 Проверить основную функциональность

**Чеклист для GameController:**
- [ ] Игра запускается
- [ ] Можно раздать карты
- [ ] Можно выбрать третью карту
- [ ] Можно выбрать победителя
- [ ] Выплаты работают
- [ ] Настройки работают
- [ ] Режим выживания работает

**Чеклист для GamePhaseManager:**
- [ ] Все фазы игры работают
- [ ] Валидация работает
- [ ] Переходы между фазами работают

**Чеклист для других классов:**
- [ ] Функциональность, которую ты менял, работает
- [ ] Связанная функциональность работает
- [ ] Нет визуальных багов

**Чеклист:**
- [ ] Игра запускается
- [ ] Основная функциональность работает
- [ ] Нет очевидных багов
- [ ] Визуально всё выглядит правильно

---

### ШАГ 6: Коммит (5 минут)

#### 6.1 Проверить изменения
```bash
# Посмотреть, что изменилось
git status
git diff

# Убедиться, что изменены только нужные файлы
```

#### 6.2 Закоммитить
```bash
# Добавить изменения
git add .

# Закоммитить с описанием
git commit -m "Refactoring: Step X.X - Description

- Что сделано
- Что улучшено
- Какие файлы изменены"
```

**Пример хорошего коммита:**
```
Refactoring: Step 2.1 - Extract CardController

- Создан CardController для управления картами
- Перемещены методы show_all_backs(), open_all_cards(), reset_cards()
- Обновлён GameController для использования CardController
- Уменьшен размер GameController на ~100 строк
```

**Чеклист:**
- [ ] Изменения проверены
- [ ] Коммит создан с описанием
- [ ] Коммит понятен для будущего себя

---

### ШАГ 7: Если что-то пошло не так

#### 7.1 Откатить изменения
```bash
# Откатить последний коммит (сохранить изменения)
git reset --soft HEAD~1

# Или откатить полностью
git reset --hard HEAD~1

# Или вернуться к конкретному коммиту
git checkout <commit-hash>
```

#### 7.2 Разобраться в проблеме
- [ ] Понять, что пошло не так
- [ ] Найти причину проблемы
- [ ] Исправить ошибку
- [ ] Повторить проверки

**Чеклист:**
- [ ] Проблема понятна
- [ ] Ошибка исправлена
- [ ] Проверки пройдены

## 💡 Советы

1. **Не торопись** - лучше медленно и правильно
2. **Тестируй часто** - после каждого изменения
3. **Коммить часто** - можно откатиться
4. **Используй AI** - спрашивай, если не уверен
5. **Следуй чеклисту** - не пропускай пункты

---

**Помни**: Рефакторинг должен улучшать код, а не ломать его!

## 🎯 Что это за проект?

**Баккара Тренажёр v5.9** - интерактивный тренажёр для обучения дилеров правилам игры в баккара на Godot 4.5.

**Основная цель**: Помочь дилерам практиковать:
- Правила добора третьей карты
- Расчёт выплат с комиссией 5% на банкира
- Расчёт выплат 8:1 на ничью
- Режим выживания с 7 жизнями

## 🏗️ Архитектура в 3 предложениях

1. **GameController** координирует все системы через менеджеры
2. **EventBus** - единственный способ межсистемной коммуникации (38+ сигналов)
3. Каждая система = отдельный менеджер (Manager Pattern)

## 🔑 Топ-5 самых важных файлов

1. **`scripts/GameController.gd`** (2024 строки) - главный координатор
2. **`scripts/autoload/EventBus.gd`** - все события проекта
3. **`scripts/GamePhaseManager.gd`** (604 строки) - игровая логика
4. **`scripts/BaccaratRules.gd`** - правила игры
5. **`scripts/UIManager.gd`** - фасад для UI

## 📡 EventBus - КАК это работает

```gdscript
# ✅ ПРАВИЛЬНО - через EventBus
EventBus.action_correct.emit("player_third")

# ❌ НЕПРАВИЛЬНО - прямые вызовы
some_manager.do_something()
```

**Все сигналы**: см. `scripts/autoload/EventBus.gd` (38+ сигналов)

## 🎮 Жизненный цикл раунда

```
WAITING → CARD_TO_EACH → CARD_TO_PLAYER/BANKER → CHOOSE_WINNER → PAYOUT → RESET
```

**Состояния**: `GameStateManager.current_state` (enum GameState)

## ⚠️ Критические правила

1. **НЕ создавать прямые зависимости** между менеджерами
2. **ВСЕГДА использовать EventBus** для коммуникации
3. **НЕ изменять сигнатуры EventBus** без обновления документации
4. **Следовать SRP** - один класс = одна ответственность
5. **Типизация обязательна** - всегда указывать типы

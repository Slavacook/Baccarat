## 💬 Чат-боты и генерация текста

### 1. Claude (Anthropic)
**🌐 Ссылка**: https://claude.ai  
**Что можно делать бесплатно**:
- Чатиться с Claude через веб-интерфейс, iOS/Android приложения
- Создавать и редактировать контент
- Анализировать текст и изображения
- Веб-поиск
- Загружать документы для анализа

**Лимиты**:
- Лимиты на сессии (обнуляются ~каждые 5 часов)
- Ограничения по количеству сообщений и объёму
- Точное число зависит от нагрузки сервера

**Примечание**: Бесплатный план даёт доступ к модели **Claude 4 Sonnet**. Есть также **Claude Haiku 4.5** — полностью бесплатный вариант для кодогенерации и рабочих задач.

---

### 2. ChatGPT (OpenAI)
**🌐 Ссылка**: https://chat.openai.com  
**Что можно делать бесплатно**:
- Чат с GPT-3.5
- Генерация текста
- Базовый анализ документов
- Простая кодогенерация

**Лимиты**:
- Неограниченные сообщения (с некоторыми ограничениями скорости)
- Доступ к GPT-3.5 без ограничений
- GPT-4 доступен платно

**Примечание**: Есть также бесплатные API кредиты для новых аккаунтов (см. раздел API).

---

### 3. DeepSeek
**🌐 Ссылка**: https://www.deepseek.com  
**Что можно делать бесплатно**:
- Web-интерфейс: **неограниченный доступ** к моделям V3 и R1
- Генерация кода
- Чат без лимита сообщений
- Рабочие задачи и анализ

**Лимиты**:
- Web-интерфейс: без лимита сообщений
- API: **5 миллионов бесплатных токенов** на старте
- Ограничения на чувствительный контент (по законам Китая)

**Примечание**: Отличный вариант для кодинга — модель DeepSeek Coder специализируется на коде.

---

### 4. Google Gemini
**🌐 Ссылка**: https://gemini.google.com  
**Что можно делать бесплатно**:
- Чат с моделью Gemini
- Генерация текста
- Анализ изображений
- Мультимодальные запросы

**Лимиты**:
- 60 запросов в минуту (RPM)
- Доступ к Gemini Pro через API (бесплатный тариф)
- Ограничения по токенам в день

**Примечание**: Бесплатный доступ через Vertex AI с $300 кредитами для новых пользователей (см. раздел Облачные платформы).

### 5. Perplexity AI
**🌐 Ссылка**: https://www.perplexity.ai  
**Что можно делать бесплатно**:
- Поиск с AI (веб-поиск + генерация ответов)
- Генерация текста
- Анализ ссылок и документов

**Лимиты**:
- 5 запросов Pro модели в день (бесплатно)
- Неограниченные запросы к базовой модели
- Бесплатный план имеет ограничения по источникам

**Примечание**: Отлично подходит для исследований — всегда приводит источники.

---

### 6. Poe (Quora)
**🌐 Ссылка**: https://poe.com  
**Что можно делать бесплатно**:
- Доступ к множеству AI моделей в одном месте
- Чат с разными моделями (GPT-4, Claude, Gemini и др.)
- Генерация текста и кода

**Лимиты**:
- Ограниченное количество сообщений в день (зависит от модели)
- GPT-4 и Claude Sonnet — платно или с ограничениями
- Базовые модели — больше лимитов

**Примечание**: Удобный агрегатор — можно попробовать разные модели в одном интерфейсе.

## 💻 API для разработчиков

### 9. OpenAI API
**🌐 Ссылка**: https://platform.openai.com  
**Что можно делать бесплатно**:
- API доступ к GPT-3.5-turbo и другим моделям
- Генерация текста через API
- Embeddings
- Fine-tuning (ограниченно)

**Лимиты**:
- **$5 кредитов бесплатно** для новых аккаунтов (≈333,000 токенов GPT-3.5-turbo или ≈6,600 токенов GPT-4)
- Кредиты истекают через 3 месяца
- Один номер телефона/аккаунт

**Примечание**: Также есть программа бесплатных ежедневных токенов (до 1M токенов/день на крупные модели) при согласии делиться данными.

---

### 10. Hugging Face Inference API
**🌐 Ссылка**: https://huggingface.co/inference-api  
**Что можно делать бесплатно**:
- Доступ к тысячам открытых моделей через API
- Текстовые модели, изображения, аудио
- Embeddings

**Лимиты**:
- ~**$0.10 в месяц** для бесплатных пользователей (≈30 запросов/день на базовых моделях)
- Модели до ~10 ГБ — бесплатно
- Rate limits и ограничения по размеру модели

**Примечание**: Огромная библиотека открытых моделей — можно найти практически всё.

## 🌐 Агрегаторы моделей

### 14. OpenRouter
**🌐 Ссылка**: https://openrouter.ai  
**Что можно делать бесплатно**:
- Доступ к множеству моделей через единый API
- Бесплатные модели (endpoints с :free)

**Лимиты**:
- **50 запросов в день** на бесплатные модели (если баланс < $10)
- **~1,000 запросов в день** на бесплатные модели (если добавить ≥ $10)
- Отдельные лимиты для бесплатных и платных моделей

**Примечание**: Удобно, если хочешь попробовать разные модели без регистрации везде.

## ☁️ Облачные платформы

### 15. Google Vertex AI / Google Cloud
**🌐 Ссылка**: https://cloud.google.com/vertex-ai  
**Что можно делать бесплатно**:
- Доступ к Gemini через Vertex AI
- ML-сервисы (текст, изображения)

**Лимиты**:

- Бесплатные квоты на разные ML-сервисы

### 16. AWS Free Tier (Machine Learning)
**🌐 Ссылка**: https://aws.amazon.com/free/machine-learning  
**Что можно делать бесплатно**:
- Amazon Transcribe (расшифровка аудио)
- Amazon Translate (перевод)
- Amazon Rekognition (распознавание изображений)
- Amazon SageMaker (ML обучение, ограниченно)
- Amazon Comprehend (NLP)

**Лимиты**:
- Бесплатно в течение **12 месяцев** после регистрации
- Лимиты по часам, объёмам текста, минутам и т.п.
- Каждый сервис имеет свой Free Tier лимит

**Примечание**: Много разных ML-сервисов, но лимиты достаточно низкие.

## 💡 Советы по использованию

1. **Регистрируйся в нескольких сервисах** — так сможешь использовать разные возможности
2. **Экономь бесплатные токены** — используй для важных задач
3. **Читай условия** — некоторые кредиты истекают через время
4. **Следи за лимитами** — многие лимиты обновляются ежедневно/ежемесячно
5. **API vs Web-интерфейс** — API обычно имеет другие лимиты, чем веб-версия

## 🎯 Описание

Интерактивный тренажёр по баккаре для дилеров и крупье: отработка правил добора третьей карты, определения победителя и расчёта выплат в учебных сценариях.

> Это учебное приложение. В нём нет ставок на реальные деньги, выигрыша реальных денег и вывода средств.

---

## ✨ Основные функции

### 🎮 Игровой процесс
- Раздача карт по правилам баккара
- Автоматический расчёт очков
- Определение победителя (Игрок/Банкир/Ничья)
- Третья карта по официальным правилам

### 💰 Система выплат
- Визуализация стеков фишек (до 20 в стеке)
- 12 номиналов: от 1 до 500,000
- Автоматическая сортировка и компактная упаковка
- Динамическое масштабирование (6→10 слотов)
- Проверка правильности выплаты

### 🎯 Режим выживания
- 7 жизней (сердечки-эмодзи)
- Потеря жизни при каждой ошибке
- Счётчик пройденных раундов
- Экран Game Over с результатом

### 🌍 Локализация
- Русский язык
- Английский язык
- Переключение на лету

## 🎮 Как играть

1. Нажмите **"Раздать"** для получения карт
2. Выберите, кто должен получить **третью карту** (если применимо)
3. Нажмите **"Раздать"** для подтверждения
4. Выберите **победителя** (Игрок/Банкир/Ничья)
5. Соберите правильную **выплату** фишками
6. Нажмите **"Выплата"** для проверки

### Режим выживания
- Активирован по умолчанию для тестирования
- Каждая ошибка отнимает жизнь
- Правильная выплата = +1 раунд
- Цель: максимальное количество раундов

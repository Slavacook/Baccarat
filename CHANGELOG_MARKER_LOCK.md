# 🔒 Блокировка маркеров во время выплат

**Дата:** 2024-12-10
**Версия:** v5.9.1

---

## 🎯 Задача

Заблокировать маркеры выбора победителя (Player/Banker) во время выплат, чтобы игрок случайно не изменил выбор.

---

## ✅ Реализация

### 1. **WinnerSelectionManager.gd**

Добавлены новые методы:

#### `lock_markers()` - Блокировка маркеров
```gdscript
func lock_markers() -> void:
    """Заблокировать все маркеры (некликабельные)"""
    for winner_type in marker_nodes.keys():
        var marker = marker_nodes[winner_type]
        marker.disabled = true
        marker.modulate = Color(1.0, 1.0, 1.0, 0.5)  # Полупрозрачные
```

**Эффект:**
- Маркеры становятся **некликабельными** (disabled = true)
- Визуально **полупрозрачные** (opacity 50%) для индикации

#### `unlock_markers()` - Разблокировка маркеров
```gdscript
func unlock_markers() -> void:
    """Разблокировать все маркеры (кликабельные)"""
    for winner_type in marker_nodes.keys():
        var marker = marker_nodes[winner_type]
        marker.disabled = false
        marker.modulate = Color(1.0, 1.0, 1.0, 1.0)  # Полная непрозрачность
```

**Эффект:**
- Маркеры становятся **кликабельными** (disabled = false)
- Визуально **полностью непрозрачные** (opacity 100%)

---

### 2. **GameController.gd**

Добавлены вызовы блокировки/разблокировки в ключевых точках:

#### 🔒 Блокировка (1 место)

**`_on_winner_selected()` - После правильного выбора победителя**
```gdscript
if chosen == actual:
    EventBus.action_correct.emit("winner")

    // 🔒 БЛОКИРУЕМ МАРКЕРЫ
    if winner_selection_manager:
        winner_selection_manager.lock_markers()

    await get_tree().create_timer(GameConstants.VICTORY_TOAST_DELAY).timeout
    // ... далее создание очереди выплат и переход в PayoutScene
```

**Момент блокировки:** Сразу после правильного выбора, но до паузы и перехода в PayoutScene.

---

#### 🔓 Разблокировка (3 места)

**1. `_on_table_prepared()` - При подготовке стола к новой игре**
```gdscript
func _on_table_prepared():
    is_table_prepared_for_new_game = true

    // 🔓 РАЗБЛОКИРУЕМ МАРКЕРЫ
    if winner_selection_manager:
        winner_selection_manager.unlock_markers()
```

**Момент разблокировки:** Когда все выплаты завершены и стол готов к новой раздаче.

**Триггер:** Событие `EventBus.table_prepared_for_new_game`

---

**2. `_on_restart_game()` - При рестарте игры (Game Over)**
```gdscript
func _on_restart_game():
    survival_rounds_completed = 0
    is_first_deal = true
    StatsManager.instance.reset()

    if is_survival_mode:
        survival_ui.reset()
        survival_ui.activate()

    // 🔓 РАЗБЛОКИРУЕМ МАРКЕРЫ
    if winner_selection_manager:
        winner_selection_manager.unlock_markers()

    phase_manager.reset()
```

**Момент разблокировки:** При рестарте после Game Over.

---

**3. `_ready()` - При начальной загрузке (не возврат из PayoutScene)**
```gdscript
if not is_payout_return:
    phase_manager.reset()
    GameStateManager.reset()

    // 🔓 РАЗБЛОКИРУЕМ МАРКЕРЫ
    if winner_selection_manager:
        winner_selection_manager.unlock_markers()
```

**Момент разблокировки:** При обычной загрузке игры (первый запуск, F5 в редакторе).

## 🔄 Жизненный цикл

### Типичный раунд:

```
1. Начало игры
   └─ 🔓 Маркеры разблокированы (unlock_markers в _ready)

2. Раздача карт
   └─ 🔓 Маркеры доступны для клика

3. Игрок выбирает победителя
   └─ Клик на маркер → маркер подсвечивается

4. Нажатие "Карты" для подтверждения выбора
   ├─ Проверка правильности
   └─ ✅ Если правильно:
       ├─ 🔒 lock_markers() - МАРКЕРЫ ЗАБЛОКИРОВАНЫ
       ├─ Пауза 1 секунда
       ├─ Создание очереди выплат
       └─ Переход в PayoutScene

5. Обработка выплат в PayoutScene
   └─ 🔒 Маркеры заблокированы (игрок не может кликать)

6. Нажатие "Завершить" в PayoutScene
   ├─ Возврат в Game.tscn
   └─ EventBus.table_prepared_for_new_game.emit()

7. Обработка подготовки стола
   ├─ _on_table_prepared()
   └─ 🔓 unlock_markers() - МАРКЕРЫ РАЗБЛОКИРОВАНЫ

8. Новый раунд (возврат к шагу 2)
```

## 📊 Визуальная индикация

| Состояние | disabled | modulate | Визуальный эффект |
|-----------|----------|----------|-------------------|
| **🔓 Разблокированы** | false | (1, 1, 1, 1) | Полная яркость, кликабельны |
| **🔒 Заблокированы** | true | (1, 1, 1, 0.5) | Полупрозрачные (50%), некликабельны |

## 🐛 Возможные проблемы

### Проблема 1: Маркеры остались заблокированными
**Симптомы:** После возврата из PayoutScene маркеры некликабельны

**Причина:** Не вызвался `_on_table_prepared()`

**Решение:** Проверить, что EventBus.table_prepared_for_new_game эмитится

---

### Проблема 2: Маркеры кликабельны во время выплат
**Симптомы:** Можно кликать на маркеры в PayoutScene

**Причина:** Не вызвался `lock_markers()` после выбора победителя

**Решение:** Проверить логику в `_on_winner_selected()`

---

## 📝 Примечания

1. **TieButton не блокируется** - так как он управляется отдельно в GamePhaseManager
2. **Проверка на null** - все вызовы защищены `if winner_selection_manager:`
3. **Полупрозрачность** - модуляция alpha 0.5 дает приятный эффект "disabled"
4. **Независимость от состояния** - блокировка работает независимо от GameStateManager

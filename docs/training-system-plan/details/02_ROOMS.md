## 1. Обзор

Комната — это центральная сущность системы тренировки. Она объединяет тренера и группу дилеров, содержит настройки тренировки, управляет доступом и хранит историю сессий.

### Жизненный цикл комнаты (визуально)

```
СОЗДАНА          АКТИВНА          С ПАССИВНОЙ СЕССИЕЙ     АРХИВИРОВАНА    ЗАКРЫТА
  │                │                      │                     │              │
  ▼                ▼                      ▼                     ▼              │
Тренер        Тренер видит          Дилеры тренируются     Доступна       Ничего
создаёт         дашборд,            в своём темпе,         только для     нельзя
комнату,        запускает           тренер видит           чтения         сделать
получает        живые сессии        результаты             (stats only)
код + PIN-ы
```

## 2. Структура данных комнаты

### 2.1 Полная модель (все поля)

```python
class Room(BaseModel):
    # === ИДЕНТИФИКАЦИЯ ===
    id: UUID                          # Уникальный ID (генерируется сервером)
    trainer_id: UUID                  # ID владельца-тренера
    room_code: str                    # Код для входа (TRAIN-A7X9)
    name: str                         # Название ("Группа А — Утро")
    
    # === НАСТРОЙКИ ТРЕНИРОВКИ ===
    settings: RoomSettings            # Вложенная модель (см. ниже)
    
    # === СТАТУС И ВРЕМЯ ===
    status: RoomStatus                # active, archived, closed
    created_at: datetime              # Когда создана
    updated_at: datetime              # Когда последний раз изменена
    archived_at: datetime | None      # Когда заархивирована
    closed_at: datetime | None        # Когда закрыта
    
    # === СТАТИСТИКА (денормализация для быстрых запросов) ===
    total_dealers: int                # Всего дилеров (активных)
    total_sessions: int               # Всего проведённых сессий
    total_rounds: int                 # Всего раундов сыграно
    last_session_at: datetime | None  # Когда была последняя сессия
    
    # === ЛИМИТЫ ===
    max_dealers: int                  # Макс. дилеров (20-100)
    max_active_sessions: int          # Макс. одновременных сессий (обычно 1)
```

### 2.2 RoomSettings — настройки тренировки

```python
class RoomSettings(BaseModel):
    # === РЕЖИМ ТРЕНИРОВКИ ===
    survival_mode: bool               # True = режим выживания (7 жизней)
    lives_count: int                  # Количество жизней (по умолчанию 7)
    
    # === ТИПЫ СТАВОК ===
    enable_main_bets: bool            # Ставки Player/Banker (всегда True)
    enable_tie_bets: bool             # Ставки на ничью
    enable_pair_bets: bool            # Ставки на пары
    
    # === ЛИМИТЫ СТАВОК ===
    min_bet: int                      # Минимальная ставка (по умолчанию 100)
    max_bet: int                      # Максимальная ставка (по умолчанию 10000)
    tie_min_bet: int                  # Мин. ставка на ничью (по умолчанию 50)
    tie_max_bet: int                  # Макс. ставка на ничью (по умолчанию 5000)
    
    # === ДЛИТЕЛЬНОСТЬ СЕССИИ ===
    session_duration_minutes: int     # Длительность живой сессии (15/30/45/60)
    max_rounds_per_session: int | None  # Макс. раундов за сессию (None = без лимита)
    
    # === ГОСТЕВЫЕ СТАВКИ ===
    enable_guest_bets: bool           # Включить виртуальных гостей
    guest_count: int                  # Количество гостей (0-6, по умолчанию 6)
    
    # === ПРОДВИНУТЫЕ ===
    enable_chance_cards: bool         # Включить карты удачи (дополнительные механики)
    enable_training_mode: bool        # Включить пошаговый режим обучения
    auto_submit_results: bool         # Автоотправка результатов (True = без подтверждения)
    result_delay_seconds: int         # Задержка перед отправкой (для ручного подтверждения, 0-30)
```

### 2.3 RoomStatus — статус комнаты

```python
class RoomStatus(str, Enum):
    ACTIVE = "active"         # Комната активна, можно проводить сессии
    ARCHIVED = "archived"     # Заархивирована (только чтение, результаты сохранены)
    CLOSED = "closed"         # Закрыта (ничего нельзя, дилеры не могут войти)
```

## 3. API-эндпоинты для работы с комнатами

### 3.1 Создать комнату

```
POST /api/rooms
Authorization: Bearer <trainer_access_token>

Request:
{
    "name": "Группа А — Утро",
    "max_dealers": 20,
    "settings": {
        "survival_mode": true,
        "lives_count": 7,
        "enable_main_bets": true,
        "enable_tie_bets": true,
        "enable_pair_bets": false,
        "min_bet": 100,
        "max_bet": 10000,
        "tie_min_bet": 50,
        "tie_max_bet": 5000,
        "session_duration_minutes": 30,
        "max_rounds_per_session": null,
        "enable_guest_bets": true,
        "guest_count": 6,
        "enable_chance_cards": false,
        "enable_training_mode": false,
        "auto_submit_results": true,
        "result_delay_seconds": 0
    }
}

Response 201 (успех):
{
    "room": {
        "id": "uuid",
        "room_code": "TRAIN-A7X9",
        "name": "Группа А — Утро",
        "status": "active",
        "max_dealers": 20,
        "total_dealers": 0,
        "total_sessions": 0,
        "settings": { ... },
        "created_at": "2026-04-12T10:00:00Z"
    },
    "pins": [
        {"pin": "482156", "dealer_slot": 1},
        {"pin": "739501", "dealer_slot": 2},
        {"pin": "105678", "dealer_slot": 3},
        ...
        {"pin": "923847", "dealer_slot": 20}
    ],
    "shareable_link": "https://baccarat-trainer.com/join/TRAIN-A7X9"
}

Response 401 (не авторизован):
{
    "error": {
        "code": "INVALID_TOKEN",
        "message": "Невалидный или истёкший токен"
    }
}

Response 403 (не тренер):
{
    "error": {
        "code": "INSUFFICIENT_PERMISSIONS",
        "message": "Только тренеры могут создавать комнаты"
    }
}

Response 422 (неверные настройки):
{
    "error": {
        "code": "INVALID_SETTINGS",
        "message": "Неверные настройки комнаты",
        "details": {
            "max_dealers": "Должно быть от 5 до 100",
            "min_bet": "Должно быть больше 0",
            "max_bet": "Должно быть больше min_bet"
        }
    }
}
```

**Логика создания:**
1. Проверить авторизацию (тренер)
2. Валидировать настройки
3. Сгенерировать уникальный `room_code` (с проверкой коллизий)
4. Создать запись в БД
5. Сгенерировать `max_dealers` PIN-кодов
6. Вернуть комнату + PIN-ы (только один раз!)

### 3.4 Обновить настройки комнаты

```
PATCH /api/rooms/{room_code}/settings
Authorization: Bearer <trainer_access_token>

Request:
{
    "settings": {
        "survival_mode": false,  // изменено
        "session_duration_minutes": 45  // изменено
    }
}

Response 200:
{
    "room": {
        "id": "uuid",
        "room_code": "TRAIN-A7X9",
        "settings": { ... обновлённые ... },
        "updated_at": "2026-04-12T15:00:00Z"
    }
}

Response 403 (не владелец):
{
    "error": {
        "code": "NOT_ROOM_OWNER",
        "message": "Только владелец комнаты может изменять настройки"
    }
}

Response 409 (активная сессия):
{
    "error": {
        "code": "ACTIVE_SESSION_EXISTS",
        "message": "Нельзя изменить настройки во время активной сессии"
    }
}
```

**Логика:**
1. Проверить, что тренер — владелец комнаты
2. Проверить, что нет активной сессии
3. Обновить только переданные поля
4. Сохранить `updated_at`

### 3.5 Архивировать комнату

```
POST /api/rooms/{room_code}/archive
Authorization: Bearer <trainer_access_token>

Response 200:
{
    "message": "Комната заархивирована",
    "room": {
        "id": "uuid",
        "room_code": "TRAIN-A7X9",
        "status": "archived",
        "archived_at": "2026-04-12T16:00:00Z"
    }
}

Response 409 (активная сессия):
{
    "error": {
        "code": "ACTIVE_SESSION_EXISTS",
        "message": "Нельзя архивировать комнату с активной сессией"
    }
}
```

**Логика:**
1. Проверить, что нет активной сессии
2. Установить `status = archived`, `archived_at = NOW()`
3. Дилеры больше не могут войти
4. Результаты и статистика сохранены (только чтение)

### 3.7 Закрыть комнату (навсегда)

```
POST /api/rooms/{room_code}/close
Authorization: Bearer <trainer_access_token>

Request:
{
    "confirm": true  // обязательное подтверждение
}

Response 200:
{
    "message": "Комната закрыта навсегда",
    "room": {
        "id": "uuid",
        "room_code": "TRAIN-A7X9",
        "status": "closed",
        "closed_at": "2026-04-12T17:00:00Z"
    }
}
```

**Логика:**
1. Проверить подтверждение (`confirm: true`)
2. Завершить все активные сессии (если есть)
3. Установить `status = closed`, `closed_at = NOW()`
4. Дилеры не могут войти, результаты сохранены 90 дней
5. Через 90 дней — автоматическое удаление (cron job)

### 3.10 Проверить код комнаты (без входа)

```
GET /api/rooms/{room_code}/check

Response 200 (комната существует и активна):
{
    "exists": true,
    "status": "active",
    "name": "Группа А — Утро",
    "total_dealers": 8,
    "max_dealers": 20,
    "trainer_name": "Иванов И."  // сокращённо
}

Response 404 (комната не найдена):
{
    "exists": false
}

Response 410 (комната закрыта):
{
    "exists": true,
    "status": "closed",
    "message": "Эта комната закрыта"
}
```

**Зачем:** Дилер может проверить код ДО ввода PIN, чтобы убедиться, что комната существует.

## 4. Валидация настроек комнаты

### 4.1 Правила валидации

| Поле | Правила | Ошибка при нарушении |
|------|---------|----------------------|
| `name` | 3-100 символов, не пустое | `NAME_TOO_SHORT`, `NAME_TOO_LONG` |
| `max_dealers` | 5-100 | `INVALID_MAX_DEALERS` |
| `survival_mode` | boolean | — |
| `lives_count` | 1-20 (если survival_mode=true) | `INVALID_LIVES_COUNT` |
| `enable_main_bets` | всегда true | — |
| `enable_tie_bets` | boolean | — |
| `enable_pair_bets` | boolean | — |
| `min_bet` | > 0 | `INVALID_MIN_BET` |
| `max_bet` | > min_bet | `MAX_BET_NOT_GREATER_THAN_MIN` |
| `tie_min_bet` | > 0 (если enable_tie_bets=true) | `INVALID_TIE_MIN_BET` |
| `tie_max_bet` | > tie_min_bet | `TIE_MAX_NOT_GREATER_THAN_MIN` |
| `session_duration_minutes` | 5, 10, 15, 30, 45, 60, 90, 120 | `INVALID_SESSION_DURATION` |
| `max_rounds_per_session` | null или > 0 | `INVALID_MAX_ROUNDS` |
| `enable_guest_bets` | boolean | — |
| `guest_count` | 0-6 (если enable_guest_bets=true) | `INVALID_GUEST_COUNT` |
| `enable_chance_cards` | boolean | — |
| `enable_training_mode` | boolean | — |
| `auto_submit_results` | boolean | — |
| `result_delay_seconds` | 0-30 (если auto_submit_results=false) | `INVALID_RESULT_DELAY` |

### 4.2 Связанные правила

| Правило | Описание |
|---------|----------|
| Если `survival_mode=false`, `lives_count` игнорируется | Не валидировать |
| Если `enable_tie_bets=false`, `tie_min_bet` и `tie_max_bet` игнорируются | Не валидировать |
| `min_bet` должно быть ≤ `max_bet` | Обязательная проверка |
| `tie_min_bet` должно быть ≤ `tie_max_bet` | Обязательная проверка (если tie включён) |

### 4.3 Пример ответа с ошибками валидации

```json
{
    "error": {
        "code": "INVALID_SETTINGS",
        "message": "Неверные настройки комнаты",
        "details": {
            "name": "Название слишком короткое (минимум 3 символа)",
            "max_dealers": "Максимум дилеров должно быть от 5 до 100",
            "max_bet": "Макс. ставка должна быть больше мин. ставки",
            "session_duration_minutes": "Длительность должна быть: 5, 10, 15, 30, 45, 60, 90 или 120 минут"
        }
    }
}
```

| Получить дашборд | ✅ | ❌ | ❌ | ❌ | ❌ |

### 5.2 Реализация на сервере (FastAPI middleware)

```python
# middleware/room_access.py
from fastapi import Request, HTTPException, Depends
from sqlalchemy.orm import Session

async def require_room_owner(
    room_code: str,
    current_user: User = Depends(get_current_user),
    db: Session = Depends(get_db)
) -> Room:
    """Проверить, что пользователь — владелец комнаты."""
    
    if current_user.role != "trainer":
        raise HTTPException(403, "Только тренеры могут выполнять это действие")
    
    room = db.query(Room).filter(Room.room_code == room_code).first()
    if not room:
        raise HTTPException(404, "Комната не найдена")
    
    if room.trainer_id != current_user.id:
        raise HTTPException(403, "Только владелец комнаты может выполнять это действие")
    
    if room.status == "closed":
        raise HTTPException(410, "Комната закрыта")
    
    return room


async def require_room_access(
    room_code: str,
    current_user: User = Depends(get_current_user),
    db: Session = Depends(get_db)
) -> Room:
    """Проверить, что пользователь имеет доступ к комнате."""
    
    room = db.query(Room).filter(Room.room_code == room_code).first()
    if not room:
        raise HTTPException(404, "Комната не найдена")
    
    if room.status == "closed":
        raise HTTPException(410, "Комната закрыта")
    
    # Тренер-владелец — полный доступ
    if current_user.role == "trainer" and room.trainer_id == current_user.id:
        return room
    
    # Дилер этой комнаты — ограниченный доступ
    if current_user.role == "dealer":
        dealer = db.query(Dealer).filter(
            Dealer.id == current_user.id,
            Dealer.room_id == room.id,
            Dealer.is_active == True
        ).first()
        if dealer:
            return room
    
    raise HTTPException(403, "Нет доступа к этой комнате")
```

## 6. Жизненный цикл комнаты (детально)

### 6.1 Этапы

```
┌──────────────────────────────────────────────────────────────────────┐
│                        ЖИЗНЕННЫЙ ЦИКЛ КОМНАТЫ                        │
└──────────────────────────────────────────────────────────────────────┘

1. СОЗДАНИЕ
   │
   │  Тренер заполняет форму → POST /api/rooms
   │  Сервер: генерирует код, PIN-ы, создаёт записи в БД
   │  Возвращает: room_code + список PIN-ов (только один раз!)
   │
   ▼
2. АКТИВНА (initial)
   │
   │  Дилеры входят по коду + PIN
   │  Тренер видит дашборд (пока пусто)
   │  Можно запустить первую сессию
   │
   ▼
3. АКТИВНА (с сессиями)
   │
   │  Тренер запускает живые сессии
   │  Дилеры тренируются асинхронно между сессиями
   │  Результаты копятся, таблица лидеров обновляется
   │  Статистика растёт: total_sessions, total_rounds, last_session_at
   │
   ▼
4. АРХИВИРОВАНА (опционально)
   │
   │  Тренер архивирует: POST /api/rooms/{code}/archive
   │  Дилеры больше не могут войти
   │  Результаты сохранены (только чтение)
   │  Тренер всё ещё видит дашборд
   │  Можно восстановить: POST /api/rooms/{code}/restore
   │
   ▼
5. ЗАКРЫТА (финальный статус)
   │
   │  Тренер закрывает навсегда: POST /api/rooms/{code}/close
   │  Требует подтверждение (confirm: true)
   │  Все активные сессии завершаются принудительно
   │  Дилеры не могут войти
   │  Результаты сохранены 90 дней
   │  Через 90 дней → автоматическое удаление (cron job)
   │
   ▼
   [УДАЛЕНА]
```

### 6.2 Что происходит при переходе между статусами

| Переход | Условие | Что происходит |
|---------|---------|----------------|
| `active` → `archived` | Нет активной сессии | Дилеры не могут войти, данные сохранены |
| `active` → `closed` | Подтверждение тренера | Все сессии завершены, 90-дневный таймер |
| `archived` → `active` | Запрос тренера | Дилеры снова могут войти |
| `archived` → `closed` | Запрос тренера | 90-дневный таймер |
| `closed` → `удалена` | Cron job (90 дней) | Все данные удалены (GDPR) |

### 6.3 Автоматические действия сервера

| Событие | Действие | Когда |
|---------|----------|-------|
| Комната создана | Сгенерировать PIN-ы, отправить email тренеру | Сразу |
| Дилер вошёл | Обновить `total_dealers`, записать `last_seen_at` | При каждом входе |
| Сессия завершена | Обновить `total_sessions`, `total_rounds`, `last_session_at` | После каждой сессии |
| Комната заархивирована | Заблокировать вход дилеров | Сразу |
| Комната закрыта | Завершить активные сессии, запустить 90-дневный таймер | Сразу |
| 90 дней после закрытия | Удалить все данные комнаты | Cron job, ежедневно |
| Дилер не заходил 30 дней | Пометить как `is_active = false` | Cron job, ежедневно |

| Может ли тренер создать комнату с 0 дилерами? | Да, min_dealers = 5 | Минимум 5 PIN-ов генерируется всегда |
| Может ли дилер войти в комнату без PIN? | Нет, PIN обязателен | Без PIN невозможно идентификация |
| Что если PIN украден? | Тренер перегенерирует PIN, старый не работает | Механизм регенерации |
| Можно ли изменить room_code? | Нет, код неизменяем | Упрощение, если нужно — создать новую комнату |
| Может ли тренер передать владение комнатой? | Нет (MVP) | Упростить, добавить позже если нужно |
| Может ли дилер быть в нескольких комнатах? | Да, отдельные записи | Один человек — несколько dealer_id |
| Сколько времени хранятся PIN-и? | Бессрочно (пока комната active) | Тренер может перегенерировать |
| Что если тренер удалит аккаунт? | Все его комнаты → archived | Данные сохранены, но никто не управляет |

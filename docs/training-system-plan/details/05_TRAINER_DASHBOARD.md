## 1. Обзор

Дашборд тренера — это основной рабочий инструмент тренера. Через него тренер видит результаты всех дилеров в реальном времени (во время живой сессии) и в исторической ретроспективе. Дашборд позволяет быстро оценить эффективность каждого дилера, выявить проблемные зоны и принять решение о дальнейшей работе группы.

### Где работает дашборд

| Платформа | Описание | Приоритет |
|-----------|----------|-----------|
| **Веб-интерфейс** | Отдельный веб-дашборд (React/Vue) — полноценный UI с графиками и таблицми | ✅ **Основной** |
| **Godot-клиент (тренер)** | Упрощённый дашборд внутри Godot-приложения — только мониторинг | 🟡 Дополнение |
| **Мобильная версия** | Адаптивный веб-дашборд для просмотра на телефоне | 🟡 Дополнение |

**Решение:** Основной дашборд — **веб-интерфейс**, т.к. тренеру нужен полноценный UI с графиками, таблицами, экспортом. Godot-клиент — только для быстрого мониторинга «на ходу».

### 3.3 Цветовая индикация

| Цвет | Порог | Значение | Действие тренера |
|------|-------|----------|------------------|
| 🟢 Зелёный | Точность ≥ 85% | Дилер справляется хорошо | Наблюдать, хвалить |
| 🟡 Жёлтый | Точность 70-84% | Есть проблемы | Обратите внимание, подскажите после сессии |
| 🔴 Красный | Точность < 70% | Критические проблемы | Срочно: после сессии — индивидуальная работа |
| ⚫ Серый | Не в сети | Дилер не подключился | Проверить, почему не зашёл |

**Дополнительные индикаторы скорости:**

| Значок | Значение | Порог |
|--------|----------|-------|
| ⚡ Быстро | < 15 сек/раунд | Отлично |
| ⏱ Нормально | 15-25 сек/раунд | Норма |
| 🐢 Медленно | > 25 сек/раунд | Нужно ускориться |

### 3.4 Алгоритм определения статуса

```python
def get_dealer_status_color(accuracy: float, speed: float) -> str:
    """Определить цвет статуса дилера."""
    if accuracy >= 85:
        return "green"
    elif accuracy >= 70:
        return "yellow"
    else:
        return "red"

def get_speed_icon(avg_time_per_round: float) -> str:
    """Определить иконку скорости."""
    if avg_time_per_round < 15:
        return "bolt"  # ⚡
    elif avg_time_per_round <= 25:
        return "clock"  # ⏱
    else:
        return "turtle"  # 🐢
```

## 6. Алгоритм автоматических рекомендаций

### 6.1 Логика

```python
def generate_recommendations(dealer_stats: dict, group_stats: dict) -> list:
    """Генерирует автоматические рекомендации для дилера."""
    recommendations = []
    
    for category, data in dealer_stats["category_accuracy"].items():
        error_rate = 100 - data["accuracy"]
        total_attempts = data["total"]
        errors = data["errors"]
        
        # Критично: точность < 60% и достаточно попыток
        if data["accuracy"] < 60 and total_attempts >= 5:
            recommendations.append({
                "priority": "critical",
                "category": category,
                "accuracy": data["accuracy"],
                "errors": errors,
                "action": "individual_training",
                "suggested_task": f"30 раздач с фокусом на «{category}»",
                "message": f"Критическая точность ({data['accuracy']}%). Требуется индивидуальная работа."
            })
        
        # Проблема: точность < 80% и достаточно попыток
        elif data["accuracy"] < 80 and total_attempts >= 10:
            recommendations.append({
                "priority": "warning",
                "category": category,
                "accuracy": data["accuracy"],
                "errors": errors,
                "action": "group_focus",
                "suggested_task": f"20 раздач с фокусом на «{category}»",
                "message": f"Есть проблемы с «{category}» ({data['accuracy']}%). Рекомендуется практика."
            })
        
        # Отлично: точность >= 95%
        elif data["accuracy"] >= 95 and total_attempts >= 10:
            recommendations.append({
                "priority": "good",
                "category": category,
                "accuracy": data["accuracy"],
                "action": "praise",
                "message": f"Отличная работа с «{category}» ({data['accuracy']}%)!"
            })
    
    # Проверка скорости
    avg_time = dealer_stats["avg_time_per_round"]
    if avg_time > 30:
        recommendations.append({
            "priority": "warning",
            "category": "speed",
            "value": avg_time,
            "action": "speed_training",
            "message": f"Медленная скорость ({avg_time}с/раунд). Рекомендуется режим «на время»."
        })
    elif avg_time < 10 and dealer_stats["accuracy"] < 80:
        recommendations.append({
            "priority": "warning",
            "category": "speed_vs_accuracy",
            "value": avg_time,
            "action": "slow_down",
            "message": f"Слишком быстрая игра ({avg_time}с) при точности {dealer_stats['accuracy']}%. Замедлитесь."
        })
    
    # Тренд (ухудшение)
    trend = dealer_stats.get("accuracy_trend")
    if trend and trend.get("direction") == "down" and abs(trend.get("change", 0)) > 10:
        recommendations.append({
            "priority": "warning",
            "category": "trend",
            "change": trend["change"],
            "action": "check_fatigue",
            "message": f"Точность падает ({trend['change']}% за последние 20 раундов). Возможно усталость."
        })
    
    return sorted(recommendations, key=lambda x: {"critical": 0, "warning": 1, "good": 2}[x["priority"]])
```

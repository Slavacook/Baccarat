## 📖 Как пользоваться этим планом

### Для менеджера

1. Откройте `00_MASTER_PLAN.md` — общая картина
2. Откройте `01_PROGRESS_SUMMARY.md` — что готово, сколько осталось
3. Откройте `02_READINESS_ASSESSMENT.md` — риски и пробелы
4. Перед каждым этапом — откройте соответствующий `details/*.md`

### Для разработчика

1. Найдите свой документ в `details/` по номеру раздела
2. Внутри каждого документа:
   - **Обзор** — что делаем и зачем
   - **API-эндпоинты** — метод, путь, запрос, ответ, ошибки
   - **База данных** — таблицы, колонки, SQL
   - **Wireframes** — как выглядит экран
   - **Тест-кейсы** — что тестировать
   - **Итог** — чеклист: что детализировано

### Порядок реализации

```
Сервер (Фаза 1)          → Godot-клиент (Фаза 1-2)      → Веб-дашборд (Фаза 4)
09_SERVER.md             → 10_CLIENT.md                  → 05_TRAINER_DASHBOARD.md
01_AUTHENTICATION.md     → 01_AUTHENTICATION.md          → 12_ANALYTICS.md
02_ROOMS.md              → 03_LIVE_SESSIONS.md           → 08_ASSIGNMENTS.md
                         → 04_ASYNC_TRAINING.md
                         → 06_LEADERBOARD.md
                         → 07_ACHIEVEMENTS.md
```

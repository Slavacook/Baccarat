# Исправление проблемы пикселизации

## Проблема

После перехода на `mode="viewport"` качество изображения упало - всё выглядело пиксельным.

## Причина

1. **Отсутствие `aspect="keep"`** - viewport растягивался непропорционально, что вызывало пикселизацию
2. **Отсутствие фильтрации текстур** - текстуры не сглаживались при масштабировании
3. **Отсутствие антиалиасинга** - края объектов выглядели неровными

## Решение

### 1. Вернули `aspect="keep"` в project.godot:

```ini
[display]
window/stretch/mode="viewport"
window/stretch/aspect="keep"  # ← ВАЖНО! Сохраняет пропорции и качество
```

**Почему это важно:**
- Без `aspect="keep"` viewport растягивается непропорционально
- Это приводит к пикселизации при масштабировании
- С `aspect="keep"` пропорции сохраняются, качество остаётся высоким

### 2. Добавили фильтрацию текстур:

```ini
[rendering]
textures/canvas_textures/default_texture_filter=2  # Linear фильтрация
```

**Что это даёт:**
- `2` = Linear фильтрация (сглаживание)
- Текстуры сглаживаются при масштабировании
- Убирает пикселизацию при увеличении

**Варианты:**
- `0` = Disabled (без фильтрации) - пикселизация
- `1` = Nearest (ближайший пиксель) - резкие края
- `2` = Linear (линейная интерполяция) - сглаживание ✅

### 3. Добавили FXAA (антиалиасинг):

**Проблема:** MSAA для 2D не поддерживается в GLES3 (gl_compatibility renderer)

**Решение:** Используем FXAA (Fast Approximate Anti-Aliasing)

**В project.godot:**
```ini
[rendering]
anti_aliasing/quality/screen_space_aa=1  # FXAA
```

**В коде (GameInitializer.gd):**
```gdscript
static func _setup_antialiasing(controller: Node2D) -> void:
    var viewport: Viewport = controller.get_viewport()
    if viewport:
        var viewport_rid: RID = viewport.get_viewport_rid()
        RenderingServer.viewport_set_screen_space_aa(
            viewport_rid, 
            RenderingServer.VIEWPORT_SCREEN_SPACE_AA_FXAA
        )
```

**Что это даёт:**
- Сглаживает края объектов
- Работает в GLES3 (в отличие от MSAA)
- Улучшает качество рендеринга
- Убирает "зубчатость" на краях
- Меньше влияния на производительность чем MSAA

## Итоговые настройки

**В project.godot:**
```ini
[display]
window/stretch/mode="viewport"      # Пропорциональное масштабирование
window/stretch/aspect="keep"        # Сохранение пропорций и качества (КРИТИЧНО!)

[rendering]
textures/canvas_textures/default_texture_filter=2  # Linear фильтрация (сглаживание)
anti_aliasing/quality/screen_space_aa=1             # FXAA (работает в GLES3)
```

**В коде (GameInitializer.gd):**
- Автоматически включается FXAA для viewport при инициализации

## Результат

После применения изменений:
- ✅ Качество изображения улучшилось
- ✅ Нет пикселизации при масштабировании
- ✅ Текстуры сглаживаются при увеличении
- ✅ Края объектов выглядят плавно
- ✅ Пропорции сохраняются
- ✅ Игра масштабируется пропорционально

## Производительность

**Влияние на производительность:**
- `texture_filter=2` (Linear) - минимальное влияние
- `screen_space_aa=1` (FXAA) - меньше влияния чем MSAA, обычно не критично
- Для 2D игр обычно не критично

**Если нужна максимальная производительность:**
- Можно отключить FXAA (`screen_space_aa=0`)
- Но качество немного ухудшится

## Примечания

- Эти настройки работают для всех платформ (десктоп, HTML5, мобильные)
- Для HTML5 экспорта качество также улучшится
- На мобильных устройствах может быть небольшое влияние на производительность, но обычно не критично

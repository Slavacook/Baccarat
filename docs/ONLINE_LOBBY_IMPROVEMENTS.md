## План доработки OnlineLobby (UX/UI)

Для того чтобы ученикам было проще подключаться к занятиям, необходимо улучшить текущий экран входа в онлайн-режим.

### 1. Улучшение ввода PIN-кода

- **Авто-фокус**: При открытии экрана фокус сразу устанавливается на поле ввода кода.
- **Маска ввода**: Ограничение ввода только цифрами (4-6 знаков).
- **Авто-валидация**: Как только введено нужное количество цифр, игра автоматически отправляет запрос `fetch_active_live_session_async(room_code)`.
- **Визуальный фидбек**:
  - Зеленая галочка, если комната найдена и сессия активна.
  - Красный текст ошибки, если код неверный или сессия завершена.

### 2. Идентификация ученика

- **Поле "Имя ученика"**: Добавить текстовое поле для ввода имени или выбора из списка (если реализовано через API).
- **Сохранение**: Последнее введенное имя сохраняется в `SaveManager`, чтобы не вводить его каждый раз.

### 3. Статус подключения

- Добавить индикатор (Spinner) во время ожидания ответа от сервера.
- Кнопка "Войти" становится активной только после успешной валидации кода комнаты.

### 4. Информационная панель

- Отображение параметров текущей сессии после валидации кода:
  - Имя тренера.
  - Название комнаты.
  - Оставшееся время сессии.

### 5. Обработка ошибок

- Понятные сообщения: "Сервер недоступен", "Комната не найдена", "Сессия еще не начата тренером".

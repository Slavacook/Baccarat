## Техническое задание: Дашборд тренера (v2)

### 1. Обзор

Дашборд тренера — это веб-интерфейс для мониторинга действий учеников в реальном времени. Основная цель: мгновенное выявление ошибок и отслеживание прогресса группы.

### 2. Основные компоненты (Frontend)

Рекомендуемый стек: **React** или **Vue.js** (для эффективного управления состоянием WebSocket).

#### А. Сетка учеников (Live Grid)

- Каждая карточка представляет одного ученика в активной комнате.
- **Индикаторы**:
  - `Status`: "В лобби", "В игре", "Ошибка!".
  - `Lives`: Визуальные сердечки (соответствуют игре).
  - `Accuracy`: Процент точности в текущей сессии.
- **Анимация**: При получении события `error_occurred` карточка должна пульсировать красным цветом.

#### Б. Живая лента событий (Live Feed)

- Вертикальный список всех событий в комнате.
- Фильтрация: "Только ошибки", "Все действия".
- Каждое событие ошибки содержит: Имя ученика, Тип ошибки, Время.

#### В. Панель управления комнатой

- Кнопка "Завершить сессию" (принудительный выход всех учеников).
- Отображение PIN-кода комнаты крупным шрифтом.

### 3. API Интеграция

- **WebSocket**: Подключение к `/ws/rooms/{room_id}/monitor`.
- **REST**:
  - `GET /api/rooms/{id}/stats` — получение агрегированной статистики.
  - `GET /api/sessions/{id}/round-results` — детальный просмотр ошибок конкретной сессии.

### 4. UX/UI Рекомендации

- Использовать темную тему (Dark Mode) для снижения нагрузки на глаза тренера.
- Звуковое уведомление при критической ошибке ученика (опционально, с возможностью отключения).

# Решение проблемы полноэкранного режима

## Проблема

Игра не заполняла весь экран в полноэкранном режиме - оставались чёрные полосы (letterboxing). Игра не масштабировалась пропорционально при увеличении размера экрана.

## Анализ

**Симптомы:**
- Кнопки позиционируются правильно (якоря работают) ✅
- Игра не заполняет весь экран - остаются чёрные полосы ❌
- Игра не увеличивается на большом экране - остаётся маленькой ❌
- На маленьком экране всё работает корректно ✅

**Причина:**
- `window/stretch/mode="2d"` масштабирует только 2D элементы, но не viewport
- Viewport остаётся фиксированного размера 1154x650
- При увеличении экрана игра не масштабируется

## Решение

Выбран **Пропорциональное масштабирование viewport** для заполнения экрана.

### Настройки в project.godot:

```ini
[display]
window/size/viewport_width=1154
window/size/viewport_height=650
window/stretch/mode="viewport"  # ← ИЗМЕНЕНО с "2d" на "viewport"
window/stretch/aspect="keep"    # ← Сохраняет пропорции
window/size/width=1154
window/size/height=650
```

### Разница между режимами:

**`mode="2d"` (старый):**
- Масштабирует только 2D элементы (спрайты, UI)
- Viewport остаётся фиксированного размера
- На большом экране игра остаётся маленькой

**`mode="viewport"` (новый):**
- Масштабирует весь viewport пропорционально
- Игра увеличивается на большом экране
- Заполняет максимально возможное пространство
- Сохраняет пропорции (с `aspect="keep"`)

### Почему "viewport" + "keep"?

**`mode="viewport"` + `aspect="keep"`:**
- ✅ Пропорционально масштабирует viewport
- ✅ Игра увеличивается на большом экране
- ✅ Заполняет максимально возможное пространство
- ✅ Сохраняет пропорции (1154:650 ≈ 1.775:1)
- ✅ Нет искажений интерфейса
- ✅ Карты и стол отображаются правильно
- ⚠️ Минимальные полосы на экранах с сильно отличающимся соотношением сторон (но игра максимально заполняет экран)

**`mode="2d"` (старый подход):**
- ❌ Viewport остаётся фиксированного размера
- ❌ Игра не увеличивается на большом экране
- ❌ Остаётся маленькой даже в fullscreen

**Вывод:** `mode="viewport"` обеспечивает пропорциональное масштабирование с заполнением экрана, что именно то, что нужно для адаптивности.

## Альтернативные варианты (если понадобятся)

### Вариант 1: Заполнить весь экран (с искажениями)

```ini
window/stretch/mode="viewport"
window/stretch/aspect="expand"
```

### Вариант 3: Компромисс

```ini
window/stretch/aspect="keep_width"   # Заполняет по ширине
# или
window/stretch/aspect="keep_height"  # Заполняет по высоте
```

## Настройки HTML5 экспорта

В `export_presets.cfg` уже правильно настроено:

```ini
html/canvas_resize_policy=2  # Adaptive - правильно!
```

Это обеспечивает адаптивность canvas в браузере.

## Результат

После применения изменений:
- ✅ Игра пропорционально масштабируется в зависимости от размера экрана
- ✅ На большом экране игра увеличивается и заполняет пространство
- ✅ Сохраняет правильные пропорции (без искажений)
- ✅ UI элементы не искажаются
- ✅ Кнопки остаются на своих местах
- ✅ Карты и стол отображаются корректно
- ✅ В fullscreen игра заполняет максимально возможное пространство
- ⚠️ На экранах с сильно отличающимся соотношением сторон могут быть минимальные полосы (но игра максимально заполняет экран)

## Тестирование

Проверить на разных разрешениях:
- 1920x1080 (16:9) - стандартное соотношение
- 1366x768 (16:9) - ноутбук
- 2560x1440 (16:9) - 2K
- 1280x720 (16:9) - HD
- 375x667 (9:16) - мобильный портрет
- 414x896 (9:19.5) - iPhone 11

## Примечания

- `mode="viewport"` обеспечивает пропорциональное масштабирование всего viewport
- Игра теперь увеличивается на большом экране, а не остаётся маленькой
- На большинстве экранов (16:9, 16:10) игра заполнит весь экран без полос
- На экранах с сильно отличающимся соотношением сторон могут быть минимальные полосы, но игра максимально заполнит доступное пространство

## Если нужен fullscreen без полос (с искажениями)

Можно использовать `aspect="expand"` вместо `"keep"`:
```ini
window/stretch/mode="viewport"
window/stretch/aspect="expand"  # Заполнит весь экран, но может исказить
```

Но это приведёт к искажениям на экранах с другим соотношением сторон. Рекомендуется оставить `"keep"` для сохранения пропорций.

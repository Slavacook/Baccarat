# Исправление ошибки "memory access out of bounds" в HTML5

## Проблема

При запуске игры на сервере в HTML5 экспорте возникала ошибка:
```
RuntimeError: memory access out of bounds
```

Ошибка происходила при попытке воспроизвести фоновую музыку в `SoundManager.start_background_music()` на строке 518.

## Причина

В HTML5 экспорте Godot использует WebAssembly (WASM), который имеет ограничения по памяти и требует полной инициализации всех систем перед использованием аудио. Попытка воспроизвести музыку сразу после загрузки игры приводит к ошибке доступа к памяти.

## Решение

Добавлена отложенная загрузка фоновой музыки для HTML5 экспорта:

### 1. Обновлён `SoundManager.start_background_music()`

- Добавлена проверка `OS.has_feature("HTML5")`
- Для HTML5 используется отложенный запуск через `call_deferred()`
- Для других платформ используется обычный запуск

### 2. Добавлен метод `_start_background_music_deferred()`

- Проверяет, что узел находится в дереве сцены
- Устанавливает stream с дополнительными проверками
- Использует `await get_tree().process_frame` для задержки
- Проверяет успешность воспроизведения

### 3. Обновлён `_load_background_music_setting()`

- Добавлена задержка в несколько кадров для HTML5
- Позволяет системе полностью инициализироваться перед загрузкой музыки

### 4. Обновлён `GameController._ready()`

- Добавлена задержка перед вызовом `_load_background_music_setting()` в HTML5
- Дополнительная страховка для полной инициализации

## Изменённые файлы

1. `scripts/SoundManager.gd`
   - Метод `start_background_music()` - добавлена проверка HTML5
   - Новый метод `_start_background_music_deferred()` - отложенный запуск
   - Метод `_load_background_music_setting()` - добавлена задержка для HTML5

2. `scripts/GameController.gd`
   - Метод `_ready()` - добавлена задержка перед загрузкой музыки в HTML5

## Тестирование

После применения исправлений:

1. Экспортируйте игру в HTML5
2. Загрузите на сервер
3. Откройте в браузере
4. Проверьте консоль браузера (F12) - не должно быть ошибок "memory access out of bounds"
5. Проверьте, что фоновая музыка воспроизводится (если включена в настройках)

## Альтернативное решение

Если проблема сохраняется, можно временно отключить фоновую музыку в HTML5:

```gdscript
func _load_background_music_setting() -> void:
	if not SaveManager:
		return
	
	# В HTML5 экспорте временно отключаем музыку из-за проблем с памятью
	if OS.has_feature("HTML5"):
		print("⚠️ SoundManager: Фоновая музыка отключена в HTML5 экспорте")
		stop_background_music()
		return
	
	# ... остальной код
```

## Дополнительные рекомендации

1. **Размер памяти WebAssembly**: Если проблема сохраняется, можно попробовать увеличить размер памяти в настройках экспорта (но это не всегда доступно в Godot 4.5)

2. **Оптимизация аудио**: Убедитесь, что аудио файлы оптимизированы для веб-экспорта (OGG Vorbis рекомендуется)

3. **Ленивая загрузка**: Рассмотрите возможность загрузки музыки только по требованию пользователя, а не при старте игры

##### 3.1. ❌ Карты (52 файла) - **НЕ УДАЛЯТЬ!**

**Статус:** Все 52 карты помечены как неиспользуемые

**Почему ложное срабатывание:**
```gdscript
// CardTextureManager.gd:31
var path = "res://assets/cards/%s_%s.png" % [value_name, suit_name]
var texture = load(path)  // Динамическая загрузка!
```

Карты загружаются **динамически** через переменные, поэтому скрипт не может найти статические упоминания в коде.

**Список карт (assets/cards/):**
- `ace_*.png`, `2_*.png`, ..., `king_*.png` для каждой масти
- `cards_atlas.png` - атлас карт

**Действие:** ❌ **НЕ УДАЛЯТЬ** - карты нужны для игры!

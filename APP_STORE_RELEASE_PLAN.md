# План Подготовки К App Store

Рабочий файл для пошаговой подготовки проекта к релизу.

Цель файла:
- держать перед глазами текущий шаг;
- идти по одному небольшому блоку за раз;
- после каждого шага останавливаться, показывать результат и только потом переходить дальше.

## Как будем работать

Правило выполнения:
1. Берем только один шаг из списка.
2. Доделываем его полностью.
3. Я пишу: `Шаг N завершен, готов переходить к следующему`.
4. Ты смотришь результат и либо принимаешь шаг, либо просишь правки.
5. Только после этого переходим дальше.

Статусы:
- `[ ]` не начато
- `[~]` в работе
- `[x]` завершено
- `[!]` нужен ввод/решение от владельца проекта

## Общая стратегия

Подготовку делим на 5 коротких этапов:
1. Привести учебные функции к релизному виду.
2. Убрать технические хвосты и рискованные места.
3. Подготовить store-facing тексты и позиционирование.
4. Подготовить экспортные настройки и релизные конфиги.
5. Собрать финальный чеклист релизной проверки.

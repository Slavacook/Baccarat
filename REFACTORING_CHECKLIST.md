# Чеклист для рефакторинга

> Пошаговый чеклист для безопасного рефакторинга кода

## 📋 Перед началом рефакторинга

### Подготовка
- [ ] Создана ветка для рефакторинга
- [ ] Сделан коммит текущего состояния
- [ ] Изучена текущая архитектура (`DEPENDENCY_GRAPH.md`)
- [ ] Понятны зависимости класса (`CLASS_INDEX.md`)
- [ ] Определена цель рефакторинга

### Анализ
- [ ] Найдены все использования класса
- [ ] Понятны все зависимости
- [ ] Определены риски изменений
- [ ] Составлен план рефакторинга

## 🔍 Анализ класса

### Метрики
- [ ] Подсчитано количество строк
- [ ] Подсчитано количество методов
- [ ] Подсчитано количество зависимостей
- [ ] Определён уровень сложности

### Проблемы
- [ ] Найдены большие методы (>50 строк)
- [ ] Найдены дублирующиеся блоки кода
- [ ] Найдены нарушения SRP
- [ ] Найдены прямые зависимости (не через EventBus)

## 🎯 План рефакторинга

### Приоритизация
- [ ] Определены критичные изменения (высокий приоритет)
- [ ] Определены важные изменения (средний приоритет)
- [ ] Определены желательные изменения (низкий приоритет)

### Разбиение на шаги
- [ ] Каждый шаг независим и безопасен
- [ ] Шаги можно тестировать отдельно
- [ ] Есть план отката для каждого шага

## 🔨 Выполнение рефакторинга

### Extract Class (выделение класса)
- [ ] Создан новый класс
- [ ] Перенесены методы и переменные
- [ ] Обновлены зависимости
- [ ] Обновлены все использования
- [ ] Код компилируется без ошибок

### Extract Method (выделение метода)
- [ ] Создан новый метод
- [ ] Старый код заменён вызовом
- [ ] Метод имеет понятное имя
- [ ] Метод имеет типизацию
- [ ] Метод имеет комментарий

### Rename (переименование)
- [ ] Найдены все использования
- [ ] Переименованы все вхождения
- [ ] Обновлена документация
- [ ] Код компилируется

### Move Method (перемещение метода)
- [ ] Определён правильный класс для метода
- [ ] Метод перемещён
- [ ] Обновлены все вызовы
- [ ] Обновлены зависимости

## ✅ После каждого шага

### Тестирование
- [ ] Код компилируется
- [ ] Игра запускается
- [ ] Основной функционал работает
- [ ] Нет регрессий

### Проверка качества
- [ ] Код следует стилю (`.cursorrules`)
- [ ] Все типы указаны
- [ ] Комментарии на русском
- [ ] Нет дублирования
- [ ] Используется EventBus (не прямые вызовы)

### Документация
- [ ] Обновлён `CLASS_INDEX.md` (если нужно)
- [ ] Обновлён `DEPENDENCY_GRAPH.md` (если нужно)
- [ ] Обновлён `CLAUDE.md` (если нужно)
- [ ] Добавлены комментарии в код

## 🎯 Специфичные чеклисты

### Рефакторинг GameController
- [ ] Использован `REFACTORING_ANALYSIS_GameController.md`
- [ ] Следуешь плану из `REFACTORING_PLAN_GameController.md`
- [ ] Вынесены обработчики в отдельные классы
- [ ] Размер класса уменьшился

### Рефакторинг UI менеджера
- [ ] Следуешь Phase 2 паттерну
- [ ] Создан отдельный UI менеджер в `scripts/ui/`
- [ ] Добавлен в `UIManager` (фасад)
- [ ] Сигналы пробрасываются правильно

### Рефакторинг с EventBus
- [ ] Прямые вызовы заменены на EventBus
- [ ] Добавлены сигналы в `EventBus.gd`
- [ ] Обновлена документация EventBus
- [ ] Все подписчики обновлены

## 🚨 Критические проверки

### Безопасность
- [ ] Нет циклических зависимостей
- [ ] Нет утечек памяти (отписка от событий)
- [ ] Нет null pointer exceptions
- [ ] Все проверки на null добавлены

### Производительность
- [ ] Нет лишних вызовов
- [ ] Нет лишних подписок на события
- [ ] Кэширование где нужно

### Совместимость
- [ ] Старый код всё ещё работает
- [ ] API не сломан
- [ ] Обратная совместимость сохранена

## 📊 После завершения рефакторинга

### Финальная проверка
- [ ] Все тесты проходят
- [ ] Игра работает полностью
- [ ] Нет регрессий
- [ ] Код стал чище и понятнее

### Метрики
- [ ] Размер класса уменьшился
- [ ] Количество методов уменьшилось
- [ ] Сложность снизилась
- [ ] Зависимости уменьшились

### Документация
- [ ] Обновлена вся документация
- [ ] Добавлены примеры использования
- [ ] Обновлены диаграммы

## 🔄 Откат изменений

### Если что-то пошло не так
- [ ] Есть план отката
- [ ] Сохранён старый код
- [ ] Можно вернуться к предыдущему состоянию
- [ ] Понятно, что пошло не так

## 💡 Рекомендации

1. **Рефакторинг по частям** - не делай всё сразу
2. **Тестируй часто** - после каждого шага
3. **Коммить часто** - чтобы можно было откатиться
4. **Используй существующие паттерны** - не изобретай велосипед
5. **Документируй изменения** - для будущего себя

---

**Помни**: Рефакторинг должен улучшать код, а не ломать его!
